# Disconnection Management & Field Survey System

A role-governed utility disconnection and revenue recovery field operations application designed for electrical/utility offices (e.g., Harishchandrapur WBSEDCL office). Enables admins to manage field staff credentials and consumer databases, while field agents survey premises, initiate phone calls, trigger GPS navigation, record actions (Disconnection, Payment, Bill Dispute, Office Team, Not Found, Reissue) with auto-watermarked photographic proof, and sync directly with Google Sheets.

### User Review & Critical Decisions

> [!IMPORTANT]
> Key decisions confirmed based on your requirements and input:
> - **Google Sheet Web Link Sync**: Supported via published Google Sheet CSV web link / Apps Script webhook for real-time live sync, accompanied by Excel/CSV download & upload tools and an in-app spreadsheet manager.
> - **Role Separation & Privacy**: Admins can manage all users, assign agencies, edit/delete/reissue consumer entries, and configure sync links. Standard field users can log in only with admin-created credentials, see and survey only records assigned to their agency/user ID, and record field actions.
> - **Bilingual Accessibility**: Instant header toggle for English and Bengali (`E | বা`) with high-contrast, large touch-friendly action cards accessible for any age group.
> - **Evidence Watermarking**: In-app camera and gallery evidence capture with automated live GPS coordinates, date/time, Consumer ID, and location stamped directly onto the saved proof.
> - **Realization & Performance Ranking**: Calculates and ranks agents/agencies based on total Outstanding Due (OSD) realized vs assigned OSD, attended counts, and disconnection completion percentages with class-wise breakdowns (Class A, B, C, D).

### 1. Overview & Core Concept

- **What It Does**: Digitizes and streamlines electricity disconnection and outstanding dues recovery. Field teams receive their designated consumer lists, search and filter by MRU, class, or location radius, call consumers directly, navigate via Google Maps, and document field actions with watermarked photographic evidence. Admins monitor real-time collection rates, reissue disputed or uncollected surveys, broadcast notices, generate meeting reports, and manage user accounts.
- **Target Audience / Persona**:
  - **Field Surveyors & Linemen**: Easy-to-use mobile-friendly interface with oversized buttons, clear amounts in Indian Rupee format (`₹`), one-tap calling, and step-by-step update modals.
  - **Office Sub-Divisional Admins / Managers**: Full visibility across all agencies (CM, MR, JG, MZ, AC, SA, RK, HB, ER), aggregated recovery totals, meeting print-outs, and consumer editing.
- **Key Value**: Eliminates manual paper disconnection lists, prevents disputed disconnects through timestamped photographic proof, tracks real-time realization percentage per agent, and keeps office records synchronized with Google Sheets.

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: Dual Google Sheet Integration (Web Link & Webhook + Local Offline Persistence)**
  - *Chosen Approach*: Allow admins to configure a Google Sheet Published Web Link (CSV) for instant data pulling, and an optional Google Apps Script Webhook endpoint for live updates. Store all state in high-resiliency browser storage with seed data matching the real Harishchandrapur WBSEDCL office dataset from the reference screenshots.
  - *Why*: Enables instant zero-setup operation without mandatory GCP credentials while giving field workers full offline resilience if network drops in rural field locations.
- **Decision 2: Client-Side Canvas Image Watermarking**
  - *Chosen Approach*: When a user takes a photo or picks from gallery, the app dynamically renders the image to an HTML5 canvas and burns an official timestamp, GPS coordinates (latitude/longitude), Consumer ID, and office seal onto the bottom corner before saving.
  - *Why*: Provides verifiable, tamper-evident proof of field inspection that works seamlessly on mobile browsers without requiring heavy server-side media processing.
- **Decision 3: Agent Scoping vs Admin Omniscience**
  - *Chosen Approach*: Store each record with an `agency` code (e.g. `AC`, `CM`, `MR`, `HB`, etc.). Field users are linked to their assigned agency and only see and update their assigned consumers. Admins can view all agencies, filter by agency, and reassign or reissue records.
  - *Why*: Fulfills the strict requirement that field staff only access their assigned work while admins maintain full management control.

#### Data Model Entities
1. **Consumer Record**:
   - `id`: Unique Consumer ID (e.g. `342092397`)
   - `name`: Consumer Name (e.g. `THE SECY,BHABANIPUR`)
   - `address`: Full address
   - `class`: Consumer Class (`A`, `B`, `C`, `D`, `Commercial`, `Domestic`)
   - `osd`: Outstanding Dues amount (number, e.g. `64877.27`)
   - `mru`: MRU Section Code (e.g. `9QS66MMR`)
   - `mobileNo`: Contact phone number
   - `lat`: Latitude
   - `long`: Longitude
   - `meterNo`: Meter identifier
   - `agency`: Assigned agency code (e.g. `AC`, `CM`, `MR`, `JG`, `MZ`, `SA`)
   - `issuedDate`: Issue date string
   - `dueDate`: Due date range string
   - `status`: `connected` | `disconnected` | `paid` | `dispute` | `office_team` | `not_found` | `reissued`
   - `priority`: `normal` | `urgent`
   - `lastActionDate`: ISO string
   - `lastActionBy`: User ID
   - `evidencePhoto`: Watermarked Base64 / URL
   - `remarks`: Inspection remarks / dispute notes
   - `amountRealized`: Amount collected (if paid or partial)

2. **User Account**:
   - `id`: Username (e.g. `harishchandrapur`, `field_ac`, `field_cm`)
   - `name`: Display Name
   - `password`: Password
   - `role`: `'admin'` | `'user'`
   - `agency`: Assigned Agency code (for field users)
   - `phone`: Contact number
   - `createdAt`: Timestamp

3. **Survey Action Log**:
   - `id`: Log entry UUID
   - `consumerId`: Consumer ID
   - `agency`: Agency Code
   - `action`: Status applied
   - `amountPaid`: Amount if collected
   - `photoUrl`: Watermarked proof
   - `timestamp`: Date & time
   - `coordinates`: `{ lat, lng }`
